# Evil Islands HQ music

This mod for Evil Islands: Curse of the Lost Soul provides high quality in-game music.

It also restores several tracks that are present in the game, but never used.

## Requirements

[eix](https://github.com/BGforgeNet/eix) 0.3.0 or later, which plays FLAC music and reads `EIX_GAIN`.

Without eix, the game plays its own MP3 tracks. The easiest way to get eix is with [EItweaks](https://github.com/BGforgeNet/EItweaks/releases).

## Installation

Download the latest release and either:

- Run the installer (`.exe`). It finds the game folder and checks that it holds `game.exe`. Uninstalling it puts the
  game's own files back.
- Or extract the zip into the main game directory.
